# Minecraft

用 **一张方块贴图** 和 **一张点阵字**，做出可存档的第一人称体素世界。

没有模型、没有字体引擎、没有天空盒。方块、快捷栏、菜单全部从这两张图里来；天空和昼夜是着色器画出来的。

当前版本：**v0.2.0**。

---

## 编译

macOS：

```bash
brew install glfw cmake
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/Minecraft
```

Linux：

```bash
sudo apt install cmake g++ libglfw3-dev libgl1-mesa-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/Minecraft
```

在 `build/` 目录运行（需要旁边的 `resources/`）。存档写在 `saves/`。

## 界面

启动先到标题，不自动进世界。

| 页面 | 能做什么 |
|------|----------|
| 标题 | 继续上次、打开存档、设置、退出 |
| 存档 | 按时间列出世界；进入、删除、新建 |
| 新建 | 起名；种子可手输或随机 |
| 设置 | 视野、视距、鼠标灵敏度、垂直同步、全屏 |
| 暂停 | Esc。世界还在，模拟停下。可回标题或切档 |
| 游戏中 | 准星、九格快捷栏、选中方块描边 |

菜单空闲时休眠，不空转 GPU。

## 气候

世界由三张独立的噪声决定：**大陆度、温度、湿度**。先分海陆，陆地上再按冷热干湿铺开十个区域。交界处高度平滑过渡，不会突然断成悬崖。

| | 干燥 | 适中 | 湿润 |
|---|---|---|---|
| **热** | 沙漠：平沙丘、仙人掌，没有高山 | 稀树草原：黄绿草、橙色树干，树很稀 | 雨林：巨木、蕨类 |
| **温** | 戈壁：沙石地表、枯灌木 | 草原：开阔草地、野花 | 森林：橡树、起伏山地 |
| **冷** | 苔原：苔藓土、残雪、碎石，无树 | 针叶林：云杉、群山 | |
| **极寒** | 雪原：终年积雪，无树 | | |

岸边：湿润地带草地直接入水；只有海洋和沙漠铺沙。

陆地上会切开弯曲的河。湿润区河网密，沙漠几乎没河。只有极地雪原的河面结一层冰，冰下仍是水。冰雪不随昼夜融化。

植物跟气候走：雨林密、草原几乎无树、沙漠腹地寸草不生。

## 昼夜

完整一天大约五分钟。按住 `T` 可以快进，方便看过渡。

| 时段 | 画面 |
|------|------|
| 白天 | 蓝天、地平线发白，户外全亮 |
| 黄昏 / 黎明 | 天顶偏紫，地平线橙红，拉得比较长 |
| 夜晚 | 深蓝夜空，户外变暗，仍有一点月光 |
| 火把 | 亮度不随时间变；夜里洞里仍然暖黄 |
| 水面 | 白天偏青，夜里压暗 |
| 水下 | 浓雾蓝绿，看不见亮天 |

天空没有贴图：抬头是天顶色，平视接到地平线，远景雾用同一套颜色，天地接在一起。时间只改天空、雾和明暗，转一天不会卡。

## 怎么画得动

不按方块逐个提交。16×16×16 的一截先拼成一份网格，GPU 一次画完这一截。一整根柱子最多八段；全是空气的那段直接跳过。

看不见的面一开始就不会进网格：

- 两块实心石头贴在一起，中间那两面扔掉。
- 只留下露在空气、水、树叶旁边的外表面。
- 画的时候再关掉朝里的背面，镜头看不到的那一侧不占填充。

所以一座山看起来是成千上万块，真正画出去的几乎只有地表那一层皮。改一块只重做它附近那几截，不用重画整个世界。镜头背后和雾以外的区块也不送去画。

## 操作

| 键 | 作用 |
|----|------|
| WASD | 移动 |
