> 当前进度：**阶段 5 完成**，下一刀 **阶段 6 持久化 + 菜单选档**。  
> 目标：从「可玩的体素沙盒原型」推进到「能挖、能攒、能存、能过夜」的单机循环。  
> 真光照见 [docs/LIGHTING.md](LIGHTING.md)；菜单 / 多存档 / 设置见 [docs/MENU_AND_SAVES.md](MENU_AND_SAVES.md)。

## 现状摘要

### 已完成（阶段 0–5）

- GLFW 窗口、OpenGL 3.3、第一人称相机（WASD + 鼠标 / 方向键）
- 着色器、纹理图集、方块数据（草 / 土 / 石 / 水 / 树 / 花草等）
- Chunk 列（8 × 16³ Section，`WORLD_HEIGHT = 128`）+ 面剔除 Mesh（solid / water / flora）
- 按相机加载视野、距离卸载、Section 视锥剔除、异步生成 / 建网、主线程限流上传
- 种子噪声地形：海洋 / 草原 / 沙漠 + 独立起伏（丘陵 / 山地）+ 树木与装饰
- 挖放、选中框、AABB 碰撞、重力 / 跳跃 / 潜行 / 飞行
- 顶点 AO + 方向光、天空渐变、距离雾、透明远→近排序
- 9 格快捷栏、准星、底部 HUD
- **流水**：水位 0–7、覆盖、双源无限水、水下雾 / 染色；水下优先打到固体

| 类别 | 现状 | 影响 |
|------|------|------|
| 持久化 | 关游戏丢世界；走出视野也丢改块；种子写死、无选档菜单 | 建造 / 挖矿没有意义 |
| 地下 | 实心地层，无洞穴 / 矿石 | 探索只有地表风景 |

- **6 必须先做**：现在走远就会把改过的 Chunk 从内存删掉，7 之后挖的矿洞会自己消失。
- **7 可以不依赖 8**：创造快捷栏仍能挖洞；但没有掉落会少一层反馈。
- **9 强烈建议在 11 之前**：暗处刷怪依赖光值，方案见 [LIGHTING.md](LIGHTING.md)。
- **8 的掉落物**是实体系统的最小切片，11 应复用同一套位置 / 碰撞 / 渲染，而不是另起炉灶。

## 做内容前要补的基础设施

这些不是玩法，但卡在前面会反复返工。

1. **改块必须能离开视野而不丢**（阶段 6 的第一项）  
   `World::unloadDistantChunks` 当前直接 `erase`。至少：脏 Chunk 写到磁盘，或改过的列常驻内存。
2. **方块 ID 扩展流程固定下来**  
   每加一种方块要改：`BlockId` → `resources/blocks/*.block` → `BlockDatabase` → 图集 UV。矿石 / 火把 / 圆石都会走这条路。
3. **物品 ≠ 方块**（阶段 8 开始）  
   水桶、掉落堆叠、工具不能再用 `BlockId` 硬撑。需要 `ItemId` + 数量；方块只是其中一类物品。
4. **HUD 能画「格子 + 图标」即可**  
   背包可沿用快捷栏的正交叠层。生命值用图标心。坐标 / FPS 文字仍后置；**菜单所需的 ASCII 点阵字在阶段 6**（见 [MENU_AND_SAVES.md](MENU_AND_SAVES.md)）。
5. **音频库（阶段 12 才需要）**  
   去掉 SFML 后工程无声音后端。到音效阶段再选 header-only（如 miniaudio），不要为了它提前加依赖。

## 阶段 6：世界持久化 + 菜单（当前）

目标：改过的方块在卸载、退出、再进后都还在；并能用 ESC 菜单选档、指定种子、改设置。没有落盘，后面所有地下工程都会被流式加载吃掉。

方案见 [docs/MENU_AND_SAVES.md](MENU_AND_SAVES.md)。摘要：

1. **脏列落盘**（mesh dirty ≠ 写盘 dirty）：卸载 / 切档 / 退出时写 `saves/worlds/<folder>/c.<cx>.<cz>`；没改过的列仍程序化生成。
2. **`world.dat`**：名字、种子、玩家位姿、飞行、快捷栏。种子不再写死 `114514`。
3. **ESC 菜单**：游戏中暂停（松鼠标、停模拟）；标题页不自动建世界。
4. **多存档**：加载 / 删除 / 随机种子新建 / 手输种子新建。
5. **设置**：FOV、视距、鼠标灵敏度、垂直同步；全局 `saves/settings.cfg`。

完成标准：标题能建两个不同种子的档；挖坑 → 走远卸载 → 走回还在；切到另一档再切回来坑还在；关游戏再开人和坑都在；ESC 暂停不会关掉窗口。

涉及：`World/WorldSave.*`、`World.cpp` 卸载 / 读列、`Game` 状态机、`Main.cpp` 输入、`UI/Menu.*`、`HudRenderer`、`Config`。

## 阶段 7：洞穴与矿石

目标：地下可探索，石头里能看到矿脉。创造模式即可验收。

1. **3D 洞穴噪声**  
   在 `fillChunk` 实心段（约海平面以下）挖空：主洞穴 + 少量蜿蜒通道。不要打穿海底形成巨型天坑（海洋柱需单独保护）。
2. **矿石替换**  
   洞穴挖空之后、装饰之前：煤（浅、常见）、铁（中）、金 / 钻石（深、稀）。新 `BlockId` + `.block` + 图集格。
3. **圆石**  
   挖石头掉落用（阶段 8）也可先当方块放进快捷栏；生成时不必铺圆石。

完成标准：草原地下能走进矿洞；能看到至少两种矿脉；海洋底部不会整片塌成洞。

涉及：`TerrainGenerator`、`World::fillChunk`、`BlockId` / `BlockDatabase`、图集。

## 阶段 8：物品闭环

目标：挖方块 → 掉落 → 走近捡起 → 进快捷栏 / 背包；背包满了不能再捡。

1. **`ItemId` + 堆叠**  
   `ItemStack { id, count }`。方块物品与 `BlockId` 一一对应即可；水桶以后再加。
2. **掉落物实体**  
   最小实体：位置、速度、短时无敌、落地碰撞（复用 AABB）。渲染用一个缩小的方块 / 图标 billboard。
3. **破坏掉落**  
   左键挖：空气不再「蒸发」。土 / 草 / 沙 / 石 / 矿 / 木头按表掉 1 个；花草可掉自身。
4. **背包 27 + 快捷栏 9**  
   `E` 开关。格子 UI 复用快捷栏画法。点击交换、滚轮仍切快捷栏。创造模式可保留「无限取块」，但生存路径走掉落。
5. **拾取**  
   玩家 AABB 膨胀一点吸附近掉落物；同种堆叠（上限 64）。

完成标准：挖一排土，地上有掉落；走近进快捷栏；`E` 能把物品挪到背包；重进存档（阶段 6）物品还在。

涉及：新建 `Item/`、`Entity/`（掉落物）、`UI/Inventory.*`、扩展 `HotbarRenderer`、`Game` 输入、存档格式加背包。

## 阶段 10：生存基础

目标：人会受伤、会在水里游，而不只是创造飞行。

1. **生命值**  
   10 颗心；HUD 画在快捷栏上方。创造 / 飞行可无敌。
2. **摔落伤害**  
   落地速度超过阈值扣血；水中落地减免。
3. **游泳**  
   眼睛在水下：重力减小、空格上浮、Shift 下潜；可短时屏息，超时扣血。
4. **死亡与重生**  
   生命 ≤ 0：掉落背包（或创造不掉）、回到出生点。出生点写入阶段 6 的世界头。
5. **（可选）饥饿**  
   没有食物链就先不做；避免半吊子系统。

完成标准：高处跳下掉心；掉进湖里能游上来；淹死 / 摔死能重生。

涉及：`Physics/Player.cpp`、`Game` HUD、`World::isCameraUnderwater` 扩展为身体浸没、存档加生命值。

## 阶段 11：实体

目标：世界上有会动的东西。建立在阶段 8 掉落物的同一套实体更新上。

1. **实体基类真正用起来**  
   现有 `Entity.h` 只有三个向量。补：AABB、`update(World&, dt)`、是否需要渲染。玩家、掉落物、生物共用碰撞步进。
2. **被动生物（猪 / 鸡，一种即可）**  
   群系地表生成；随机游走 + 避实心；玩家靠近可被推动。击杀掉落（阶段 8）。
3. **敌对生物（僵尸，一种即可）**  
   夜间或暗处（光值阈值，见 [LIGHTING.md](LIGHTING.md)）生成；直线走向玩家；碰到就扣血。日出或高光处燃烧可后置。
4. **生成上限**  
   每 Chunk / 全图数量封顶，避免拖死主线程。不走异步 AI。

完成标准：草原能看到一种动物在走；关掉创造后，黑暗处会被一种怪物碰到掉血。

涉及：`Entity.h` 重做、新建 `Entity/*`、`World` 或 `Game` 的实体列表、简易立方体 / 广告牌渲染。
