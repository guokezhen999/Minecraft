# 地平线发绿

平视看远处时，天地交界一条偏绿，不像天空色。

**现状**：雾距仍是视距 × `0.55` / `0.92`，没有按俯仰加雾。黄昏雾色仍是 `mix(nightFog, skyHorizon, day01)`。下面是当时的改雾方案，还没落地。

---

## 现象

站在开阔草地 / 森林，视线接近水平，看远景：雾带把地面和天空接在一起的那一截发绿。低头看近处、或抬头看天，都不明显。

## 原因

空气雾是距离线性混合：

```text
fogFactor = (fogEnd - dist) / (fogEnd - fogStart)
color     = mix(fogColor, 地形色, fogFactor)
```

白天 `fogColor` 已经等于 `skyHorizon`（蓝灰）。但地平线上大片是**绿草**，中间态就是蓝雾 × 绿草 → 灰绿条。

雾结束在视距的 0.92 倍（`World::getAtmosphere`），平视时草地轮廓还落在这段 lerp 里，绿就会顶到天边。

不是贴图坏了，也不是群系色错了。

## 不做

- 改草方块颜色来「补」地平线
- 水下雾（那是另一套蓝绿，不要搅在一起）
- 体积雾、延迟渲染

---

## 做法

目标：平视时，远景在碰到绿草轮廓之前就接到 `skyHorizon`，和天空着色器地平线同一色。

优先顺序（能一条过验收就停）：

1. **收雾**  
   把 `fogEnd` 再提前（例如视距 × 0.75～0.85），让加载边缘全是雾色。若近处变得太糊，只加 `fogStart`，让过渡更短、绿带更窄。

2. **水平方向加雾**  
   片元视线 `dir.y` 接近 0 时提高雾量（或缩短 fogEnd）。低头看脚边仍清楚，平视远景更快接到天。

3. **天空 / 雾接缝**  
   `chunk.frag` 的 `fogColor` 与 `sky.frag` 的 `skyHorizon` 必须同一帧同一值（现在白天已经是）。改雾距离后看一下黄昏：`fogColor` 不要再用 `mix(nightFog, skyHorizon, day01)` 和地平线对不齐。

不要在雾里混草绿色。

---

## 步骤

0. 白天、平视、视距默认，对着大片草地截图，确认绿带还在（对照用）
1. 先只改 `fogStart` / `fogEnd`，看绿带是否消失、近处是否还能看清
2. 若 1 让近景太糊，再在 `chunk.frag` 用视线俯仰加强水平雾
3. 黄昏 / 夜晚各看一次，雾色仍贴天空地平线

---

## 验收

- 白天平视草原 / 森林远景：天地交界是天空色，没有一条明显绿带
- 近处草、树颜色不变
- 黄昏、夜晚同样没有绿边
- 水下观感与现在一致

---

## 改动面

| 模块 | 改什么 |
|---|---|
| `World::getAtmosphere` | `fogStart` / `fogEnd` 比例；雾色对齐 `skyHorizon` |
| `resources/shaders/chunk.frag` | 可选：按视线 `dir.y` 加强水平雾 |
| `SkyRenderer` / `sky.frag` | 一般不用改；只保证地平线色与雾一致 |
