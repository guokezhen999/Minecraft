# v0.2.0 总览

地形优化。仍用 **2D 高度图**，不上 3D 密度噪声、不做洞穴。相对 v0.1.0：气候从「一条噪声切海洋 / 草原 / 沙漠」换成温度×湿度，高度和植物跟群系挂钩，并补沙砖、寒带冰雪、稀树草原、河流。

详细规划：[TERRAIN.md](TERRAIN.md)。

v0.1.0 说明仍在 [../v0.1.0/OVERALL.md](../v0.1.0/OVERALL.md)。

---

## 相对 v0.1.0 改什么

1. **岸边不再强制沙子**：森林 / 草原接到水边可以是草或土，只有海洋底和沙漠才铺沙。
2. **沙砖**：沙漠里沙子和石头之间加一层沙砖，新方块 + 图集格。
3. **寒带**：雪方块地表、水面表层结冰，新方块 + 图集格。
4. **稀树草原**：草顶绿偏黄、树干偏橙、树叶绿偏黄，树很稀。
5. **高度跟群系走**：沙漠几乎没有高山；山脉主要出现在森林、针叶林、雨林。雪原和戈壁很平。
6. **河流**：陆地上用 2D 脊线噪声切开到海平面以下，灌水；**只有雪原**河面结冰。
7. **气候与植物**：大陆度 + 温度 + 湿度三张 2D 噪声定群系；树木 / 草 / 仙人掌密度查表，不再所有草地同一套。
8. **地平线发绿**：平视远景时雾把绿草和蓝天勒在一起，交界偏绿。原因和改雾方案见 [HORIZON_FOG.md](HORIZON_FOG.md)；当前雾距仍是视距 × 0.55～0.92，没有按俯仰加雾。

---

## 本版不做

- 3D 噪声、洞穴、矿石
- 季节（冰雪不随昼夜融化）
- 壁挂冰、薄雪层（雪是整格实心方块）
- 河水流动模拟（生成时灌源水即可）
- 存档升级迁移旧地形（未改过的列会按新生成器重算）
