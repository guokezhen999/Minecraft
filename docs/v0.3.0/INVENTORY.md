# 背包与草地

E 打开创造背包。草地只有一种，外观跟群系走。

---

## 背包

- `E` 开 / 关。Esc 从背包回到游戏。
- 点目录里的方块，放进当前选中的快捷栏格。
- 点底部快捷栏换选中格；1–9、滚轮照旧。
- 目录里不出现稀树草原 / 针叶林 / 苔原的「另一种草块」。

存档快捷栏若还是旧的 `SavannaGrass` 等 id，读档时收成 `Grass`。

---

## 一种草地

世界只存 `Grass`。建网时按该列群系换贴图：

| 群系 | 外观 |
|------|------|
| 森林 / 草原 / 雨林 / 其它 | 翠绿草 |
| 稀树草原 | 黄绿草 |
| 针叶林 | 针叶林草 |
| 苔原 | 苔藓土 |

稀树草原、针叶林、苔原的地表生成也改写 `Grass`，不再写三种草 id。旧列里残留的变体 id 建网时同样按群系贴图，看起来一致。
