# v0.3.0 总览

日光全局光照（beta）。光图、火把、昼夜周期都不改；改的是**怎么用这些光**。

详细规划：[DAYLIGHT_GI.md](DAYLIGHT_GI.md)。

v0.2.0 地形说明仍在 [../v0.2.0/OVERALL.md](../v0.2.0/OVERALL.md)。v0.1.0 光图规则仍在 [../v0.1.0/LIGHTING.md](../v0.1.0/LIGHTING.md)。

---

## 相对 v0.2.0 改什么

1. **直射太阳**：着色器按面朝向 × 太阳方向做 Lambert。上午东墙亮，下午西墙亮。
2. **天空间接光**：现有 `skyLight` 当作「看得到多少天」，乘上天空色。树荫、屋檐、北墙偏冷，不是单纯变灰。
3. **AO 和 cardinal 拆开**：建网只烘焙四角 AO；顶/侧/底的明暗不再写死在网格里。
4. **太阳 / 月亮圆盘**：天空着色器画出来，和地面光照同一套方向。
5. **昼夜仍只改 uniform**：转一天不 remesh、不重算光图。

---

## 本版不做

- 阴影贴图、延迟渲染、体积光
- 按太阳方向重算天空柱（会整图 remesh）
- 屏幕空间 GI / 体素锥追踪 / 光追
- 地面把光染成草色的二次弹射
